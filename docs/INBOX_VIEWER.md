# June inbox viewers

Messages groups collected WhatsApp messages by conversation. Mail offers Focused, All, Deadline, Opportunity and Promotion filters. Local Qwen can summarize and categorize saved text. All-unread summaries run as durable batches and require explicit read acknowledgement. Attachment indicators contain metadata only.

See [Inbox and tasks](INBOX_TASKS.md) for task-board, reminder and research behavior. Configure private accounts before running services. Opening messages does not send replies or read receipts.
